# FMAP-0001 — Birth of the Arcology Polymorphic Substrate

FMAP-0001 is the master program for the substrate: compiler mechanisms, A-MIR contracts, runtime
handles/resources, firmware transition, PRD, virtual memory, execution contexts, capabilities,
providers, and diagnostics. Each phase requires an RFC, ArcoBASIC policy source, validation
fixtures, documentation, and an implementation report. No subsystem may bypass substrate resource
or ownership rules.
